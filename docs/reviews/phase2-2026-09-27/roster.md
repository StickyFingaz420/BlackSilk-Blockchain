# Phase 2 roster: 50 specialist workstreams

Every agent reads `C:/bszkeval/p2/brief.md` first. Each entry defines:

- **Scope:** files and modules to inspect.
- **Q:** research and security questions to answer, in addition to the standard 14 in the brief.
- **Accept:** what phase 2 must deliver.
- **Tests / Bench / Docs:** required tests, benchmarks and documentation.

Ownership (for phase 2 writes) is listed in each dossier's implementation plan. The coordinator assigns final ownership.

## A. Consensus

- **Scope:**

  - `chain/src/block.rs`, `chain/src/emission.rs`

- **Q:**

- **Tests:** property tests over random delivery orders; a reorg across activation.

### 03 difficulty-lwma
